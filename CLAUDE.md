When working with W&B (Weights & Biases) logging, always check `define_metric` configurations and `step_metric` settings first before suggesting manual panel creation or other UI workarounds. Auto-charting depends on correct metric definitions.

In MTP (multi-token prediction) and recurrence architectures, always clarify which representation (raw hidden states vs. combined/aggregated output) should be fed to the next step. Ask if unclear.

When a bug fix or code change doesn't produce expected results after the first attempt, stop and re-examine the root cause from scratch rather than making incremental adjustments to the current approach.

Remember to ask clarifying questions if there is any ambiguity in the requirements or if the provided information is insufficient to proceed with a solution. It's better to ask than to make incorrect assumptions.
